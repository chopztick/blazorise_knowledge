# Blazorise Specifications

Learn about how Blazorise components work.

Many components grow to be quite complex in features. In addition, certain combinations might have different behaviors.

In this section, we document and specify the behavior we've designed for the more complex components and how certain combinations are expected to work and behave. In addition, particular behaviors that may help with corner cases our users might have found are also documented.

If something is not working as described or you have suggestions on how something should work differently, please open up an issue at our Github Repository.
