# Blazorise DataGrid: Getting Started

The DataGrid component is used for displaying tabular data. Features include sorting, searching, pagination, content-editing, and row selection.

To create a basic grid in Blazorise you need to set the Column that will define the grid structure and behavior.

- &lt; DataGrid&gt; the main container
    - &lt; DataGridColumns&gt; container for datagrid columns
        - &lt;DataGridColumn&gt; column template for text editor
        - &lt;DataGridNumericColumn&gt; column template for numeric values
        - &lt;DataGridDateColumn&gt; column template for datetime values
        - &lt;DataGridCheckColumn&gt; column template for boolean values
        - &lt;DataGridSelectColumn&gt; column template for selectable values
        - &lt;DataGridCommandColumn&gt; column template for editing commands like Edit, Save, Cancel, etc.
    - &lt; DataGridAggregates&gt; container for datagrid aggregates
        - &lt;DataGridAggregate&gt; defines the column and aggregation function type

## Installation

### NuGet

Install extension from NuGet.

```
Install-Package Blazorise.DataGrid
```

### Imports

In your main  add:

```
@using Blazorise.DataGrid
```

### Nested fields

Field attribute also supports nested fields. You can define a column with field name like  and it will work. Just keep in mind that when editing nested fields they must be initialized first or otherwise they will raise an exception.

DataGrid supports the

feature. We've found out, that there might be a few caveats when using the feature. For most cases you'll be just fine with removing the explicit references to the Generic Type on the children component. But for the very few cases that Blazor complains that it cannot compile, just explicitly define the Generic Type.
        Here's an example:

This will not work:

&lt;DataGridAggregate Field="@nameof( Employee.IsActive )" AggregationFunction=@(DataGridAggregate&lt;Employee&gt;.TrueCount) /&gt;

These will work:

&lt;DataGridAggregate Field="@nameof( Employee.IsActive )" AggregationFunction=@((x,y) =&gt; DataGridAggregate&lt;Employee&gt;.TrueCount(x,y)) /&gt;

&lt;DataGridAggregate TItem="Employee" Field="@nameof( Employee.IsActive )" AggregationFunction=@(DataGridAggregate&lt;Employee&gt;.TrueCount) /&gt;
