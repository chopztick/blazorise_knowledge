# BlazeStack - Admin &amp; Dashboard Template - Blazorise Themes

<!-- image -->

BlazeStack - Admin &amp; Dashboard Template is a responsive Blazorise administrator dashboard built
        for everyone who wants to create web apps on top of the most popular frameworks, Bootstrap, Bulma &amp; AntDesign.
        BlazeStack helps you to create your next Blazorise even faster than before. It can be used to create a
        Saas based interface, administrator dashboard, or anything you want to build on the web.
        BlazeStack helps your team moving faster and saving development costs.
